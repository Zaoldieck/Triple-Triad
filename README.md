# Triple Triad

A recreation of the Triple Triad card game from Final Fantasy VIII, developed in Python.

## Goal

The goal of this project is to recreate the original game mechanics as faithfully as possible while using the project as a way to learn software development and Python.

Once the original experience is complete, the project may be expanded with custom cards, new rules, additional game modes, and other original features.
